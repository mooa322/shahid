## ✨ المميزات الرئيسية

- 🚀 **إنشاء حسابات تلقائي:** دعم التسجيل المباشر السلس واستقبال رموز التأكيد التلقائية.
- 📬 **نظام قائمة الإيميلات (دفعة واحدة حتى 100 إيميل):** إمكانية إدخال لستة إيميلات مسبقة، وتحديد العدد المطلوب إنشاؤه، مع استمرار البوت تلقائياً حتى إكمال الدفعة وحذف الإيميلات المكتملة لمنع التكرار.
- 👑 **لوحة تحكم إدارية متكاملة:** إدارة المشرفين وتعيين الأدمن الأساسي (`1291024378`).
- 💎 **نظام المشتركين ونقاط البيع (POS):** تحديد فترات الاشتراك، والحد الأقصى للحسابات، وحظر أو تمديد الاشتراكات.
- 📑 **كشف حسابات شامل:** استخراج تقارير تفصيلية عن الحسابات المنشأة لكل أدمن أو مشترك.
- 💾 **نسخ احتياطي واستيراد شامل:** حفظ واسترجاع كافة البيانات والإعدادات والمشتركين بنقرة واحدة.
- 🔄 **تحديث تلقائي من GitHub:** خيار مدمج في القائمة لسحب أحدث التحديثات من المستودع مباشرة بضغطة زر دون فقدان أي بيانات.
- 🖥️ **دعم سيرفرات VPS (Ubuntu 24.04 LTS):** تشغيل المتصفح في الخلفية عبر شاشة افتراضية متطورة (`Xvfb`) لتفادي الكشف والحظر.

## 🚀 التثبيت السريع على سيرفر VPS (Ubuntu 24.04 LTS)

قم بتنفيذ الأوامر التالية بصلاحيات `root`:

```bash
# 1. سحب المستودع إلى السيرفر
git clone https://github.com/mooa322/shahid.git /opt/shahid-bot

# 2. الدخول لمجلد المشروع
cd /opt/shahid-bot

# 3. تشغيل سكريبت التثبيت التلقائي الشامل
sudo bash setup_ubuntu24.sh
```

يقوم السكريبت تلقائياً بـ:
1. تثبيت كافة حزم ومكتبات النظام اللازمة لنظام Ubuntu 24.04 (مثل `libasound2t64`, `xvfb`, `xauth`).
2. إنشاء بيئة Python 3.12 الافتراضية معزولة (`.venv`) متوافقة مع معيار PEP 668.
3. تثبيت متصفح Chromium التابع لـ Playwright مع كافة ملحقاته.
4. إعداد ملف التكوين `.env` وقائمة المشرفين.
5. إنشاء وتفعيل خدمة النظام `shahid-bot.service` بالخلفية لتعمل 24/7.
6. ربط الأمر السريع العالمي `shahid` في `/usr/local/bin/shahid`.

## 🕹️ لوحة الإدارة التفاعلية (Terminal Menu)

بعد التثبيت، يمكنك في أي وقت كتابة الأمر التالي في أي طرفية بسيرفرك لفتح لوحة التحكم:

```bash
shahid
```

```text
  SHAHID BOT MENU
  ─────────────────────────
  Status: RUNNING
  ─────────────────────────
  1) Service status
  2) Start bot
  3) Stop bot
  4) Restart bot
  5) Recent logs
  6) Live logs
  7) Manage Admins (إدارة الأدمن)
  8) Manage Subscribers (إدارة المشتركين / نقطة البيع)
  9) User Account Statement (كشف حسابات لأي أدمن أو مشترك)
  10) Backup & Restore (النسخ الاحتياطي والاستيراد الشامل)
  11) Test Playwright (فحص تشغيل المتصفح)
  12) Ubuntu 24 VPS Setup & Diagnostics (تثبيت وفحص بيئة أوبنتو 24)
  13) Update from GitHub (تحديث السكريبت والبوت من جيتهب)
  0) Exit
```

## 🔄 كيفية التحديث إلى أحدث إصدار

يمكنك تحديث البوت والسكريبت بأحدث المزايا من المستودع بإحدى طريقتين:

### الطريقة الأولى (من لوحة التحكم):
اكتب `shahid` ثم اختر **`13) Update from GitHub`**. سيقوم السكريبت تلقائياً بأخذ نسخة احتياطية من بياناتك واشتراكاتك، سحب التحديثات، تحديث الحزم، وإعادة تشغيل البوت.

### الطريقة الثانية (عبر الأوامر):
```bash
cd /opt/shahid-bot
git pull origin main
sudo systemctl restart shahid-bot
```

## ⚙️ أوامر النظام (Systemd)

```bash
# تشغيل البوت
sudo systemctl start shahid-bot

# إيقاف البوت
sudo systemctl stop shahid-bot

# إعادة التشغيل
sudo systemctl restart shahid-bot

# متابعة السجلات الحية
sudo journalctl -u shahid-bot -f
```
